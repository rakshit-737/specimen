# Security Policy

## Scope
SPECIMEN is a defensive analysis tool for lab use only. The MVP does not execute samples. It analyzes their bytes and replays behavior traces that were recorded or synthesized elsewhere.

## Reporting a vulnerability
Please open a private security advisory on the repository, or email the maintainer. Do not attach live malware. Send a hash and a description instead.

## Handling rules for contributors
- Never commit real malware, packed samples or password-protected archives. `.gitignore` blocks common formats.
- Test fixtures must stay inert. They are generated by `specimen/lab_fixtures.py` and contain no executable code.
- Any future detonation code must default to fail-closed: if network isolation is not verified, it must not run.
- Auto-generated YARA and Sigma rules are `experimental` and must not be deployed without review.
